# DOGMA Registry

Public records for completed Cult OS DOGMA audits.

Each file binds an audit to its public pull request, pinned commit and Base payment receipt. Records use `cultos.dogma.registry.v1` and are stored under:

```text
audits/YYYY/MM/<review-id>.json
```

[Open DOGMA](https://cultos.dev/dogma) · [Source](https://github.com/thesmithdao/cultos)
